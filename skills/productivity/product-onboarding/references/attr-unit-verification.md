# 属性参数单位验证 — 从船加网提取

## 方法

当新增产品分类的参数模板时，属性参数的单位必须与船加网现有筛选器一致。

```bash
# 1. 找到对应分类的 cat 参数（从 product_menu.html 获取分类树）
curl -sL "https://www.boatplus.cn/product/product_retrieval_list.html" \
  | grep -oE "cat=[0-9_]+[^>]*>[^<]+"

# 2. 访问任意子分类页面，提取筛选器及其值（包含单位）
curl -sL "https://www.boatplus.cn/product/product_retrieval_list.html?cat=164_326_329_" \
  | sed 's/<[^>]*>//g' | grep -A2 "参数名" 

# 3. 从筛选器下拉值中推断单位
# 例：筛选器显示 "0-10m" → 单位是 m
# 例：筛选器显示 "0-10kn" → 单位是 kn
# 例：筛选器显示 "0-5p" → 单位是 p (persons)
```

## 已确认的属性参数

### 船舶建造 (cat=164)
| 参数 | 单位 | 说明 |
|------|:--:|------|
| 总长 | m | 筛选器 0-10m, 10-20m, ... |
| 航速 | kn | 筛选器 0-10kn, 10-20kn, ... |
| 最大乘员 | p | 筛选器 0-5p, 5-10p, ... |
| 船体材料 | — | 文字型，筛选器直接显示材料名 |

## 注意事项
- 属性参数 = 船加网产品列表页的**筛选器**
- 筛选器的下拉值格式即为单位格式（含大小写）
- 文字型属性参数（如船体材料）无单位，模板第3行留空
- 不要凭经验猜测单位，每次新品类必须重新 curl 验证
