# 排版任务书模板

> 用于第二阶段：AI 无法直接排版详情图时，产出此任务书交给人类设计师执行。

---

## 任务书结构（8 章）

```
封面 → 规格+结构 → 系列总览表 → 各系列缩略图 → 共用素材 → 案例匹配 → 导航+注意事项
```

---

## 编写流程

### 第一步：与用户确认
1. 产品系列清单（从 SKU 表提取）+ 每个系列在 PDF 的页码和裁取区域
2. 案例匹配结果（型号不在 SKU 表中的案例丢弃）
3. 跳转链接列表（用户拍板，通常 4 条）
4. 企业介绍板块取舍（4 板块：产品覆盖→企业定位含股东→资质→生产）

### 第二步：生成标注缩略图
- 用 pymupdf 渲染 PDF 页面，**DPI ≥ 60**（36 DPI 模糊不可辨）
- 在缩略图上绘制裁切框（`draw_rect`）+ 半透明填充
- **共享区块用绿色框**（③企业定位/④资质/⑤生产 → 所有详情图相同），独立区块用蓝色框
- 标注裁取区域名称（`insert_text`）
- 文件命名：`thumb_{描述}.png`，存于桌面 `倍豪_排版缩略图/`

### 第三步：填充模板
- 系列缩略图嵌入对应段落（用 Markdown `![]()` 或 PDF 中插入图片）
- 案例紧跟产品介绍之后（板块②），不在底部
- 4 条导航链接按相关性穿插在不同位置（不在底部堆砌）

---

## 板块结构（从上到下）

```
① 产品图片区 —— 从 PDF 对应产品页裁取
    └ [链接A] 更多全回转推进器 →     ← 引导浏览同类
② 工程案例 —— 匹配本系列的具体案例
    └ [链接B] 电力推进系统 →         ← 案例多涉及电推
③ 企业定位 —— 统一文案 + 第 4 页插图
    └ [链接C] 船舶自动化产品 →       ← 展示更广产品线
④ 资质认证 —— 从第 6 页裁取
⑤ 生产能力 —— 从第 25 页裁取
⑥ 导航区
    └ [链接D] 侧向推进器 →           ← 补全产品矩阵
```

## 各章节内容规范

### 一、总体规格
| 项目 | 值 |
|------|-----|
| 宽度 | 1660 px |
| 色彩 | 白底或浅色（不要深色技术风） |
| 字体 | 思源黑体 / 微软雅黑 / PingFang SC |

### 三、产品系列清单
每个系列包含：
- PDF 素材页 + 缩略图
- ⚠️ 特别提醒（如同一页有多个系列需区分）
- SKU 型号范围
- 匹配案例

### 四、统一素材板块
三个共用板块直接从指定 PDF 页裁取：
- 企业定位（p4）
- 资质认证（p6）
- 生产能力（p25）

### 五、工程案例匹配表
4 列表格：案例名称 | 船东/船厂 | 关键供货 | 适用系列

### 六、导航链接
4 条链接用列表说明：# | 链接文字 | 穿插位置 | 设计意图

### 七、排版注意事项
- 页码清理（y ≤ 735pt）
- 图片衔接（渐变过渡）
- 不要重新打字（保留 PDF 原版视觉）
- 同一页多系列区分（如 p14 左导管式右敞开式）
- 案例取舍规则

---

## PDF 生成注意事项

如果输出为 PDF（而非 Markdown）：
- **底色必须用白色**（背景深色会导致文字渲染异常）
- 中文必须指定字体（pymupdf 用 `fontname='china-s'`，或系统路径）
- 表格用 `draw_rect` + `insert_textbox` 组合
- 缩略图加灰色细边框（0.5pt）与正文区分
- **生成后务必打开验证**：pymupdf 文字渲染可能丢字或错位
