# 船加网分类浏览方法

## 基本原则
当需要判断产品归属分类时，**主动浏览船加网产品列表**，不要等用户告诉你分类名。船加网有完整的分类树，直接在页面里找。

## 浏览入口

站点结构较简单，核心入口只有一个：

```
https://www.boatplus.cn/product/product_retrieval_list.html
```

用 curl 抓取完整 HTML（`curl -sL`）后，分类信息在两类位置：

### 1. 分类树（完整层级）
分类 ID 以 `cat=` 参数形式出现在链接中，格式为 `一级ID_二级ID_三级ID_`：

```
cat=159_168_189_  → 动力装置 > 推进装置 > 侧向推进器
cat=162_208_255_  → 电气 > 船用控制设备 > 其他设备遥测控制系统
cat=162_202_766_  → 电气 > 船舶自动化 > 船舶综合自动化
```

提取命令：
```bash
curl -sL "https://www.boatplus.cn/product/product_retrieval_list.html" \
  | grep -oE 'cat=[0-9_]+[^"]*>[^<]+' \
  | sort -u
```

或用 Python 正则：
```python
import re
cats = re.findall(r'cat=([0-9_]+)[^>]*>([^<]+)<', html)
```

### 2. 关键词统计（确认某类产品存在）
快速验证船加网是否已有某类产品：
```bash
curl -sL "https://www.boatplus.cn/product/product_retrieval_list.html" \
  | grep -oiE "关键词1|关键词2|关键词3" \
  | sort | uniq -c | sort -rn
```
