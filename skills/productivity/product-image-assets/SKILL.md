# 产品图与 LOGO 资产生成

为船加网(boatplus.cn)产品入驻生成配套的产品图（800×800）和 LOGO 图（参照倍豪尺寸：品牌logo 400×182 + 供应商logo 290×254）。

## 触发词

"产品图"、"LOGO图"、"配套图片"、"产品图片"、"800×800"、"品牌logo"、"供应商logo"

## 核心原则

1. **极简原则**：产品图就是干净的产品照片 + 版本标签，不要搞设计（渐变、场景叠加、装饰元素）
2. **LOGO 不改**：绝不自己创造、改编、配色企业 LOGO。用官方原文件，只缩放裁剪
3. **SKU 区分**：同产品不同 SKU 通过截取位置/标签文字区分，不靠额外设计元素
4. **先看参照**：不确定风格时先去看船加网上同类产品图长什么样

## 产品图规格（800×800）

### 设计规则
- 正方形截取原图（宽高取 min），保证船体完整居中
- 截取位置需避开画面中的干扰文字
- 白底或原图自然背景，不加装饰
- 底部标签条：88px 半透明黑底 `rgba(0,0,0,190)` + 阿里普惠 85-Bold 白字 40pt 居中
- 右上角：白色反白 LOGO（190×65 或 260×89，视画面定）
- 颜色标签用于 SKU 区分（如金色=汽油版、电光蓝=电动版），但仅限标签条，不扩散到整图

### 命名规则
`欧卡_SKU-{序号}_沧巡_产品图_{版本}.png`
- SKU 序号从 `欧卡_船舶建造_SKU归类表.xlsx` 中读取（临时序号列）

### 操作步骤
1. 从用户获取产品原图（高清，船体清晰）
2. 定位船体边界（重心、宽度），计算正方形裁剪窗口
3. 用户确认裁剪区域后，缩放到 800×800
4. 添加底部标签条 + 右上角反白 LOGO
5. 用户确认后定稿，按 SKU 序号命名

### 常见迭代
- **船显示不全** → 船体宽度可能超过正方形，需和用户确认取舍
- **截图偏左/偏右** → 以船体中心定位，微调 crop_left
- **标签不够显眼** → 加大 bar 高度/字体/不透明度，不是加鲜艳颜色
- **LOGO 太小** → 逐步放大直到用户满意，别一次跳太多

## LOGO 图规格

### 品牌logo（400×182 横版）
- 使用企业官方 LOGO 原文件
- 裁净白边后，左右撑满（留 12px 边距），上下居中
- 白底，不添加任何装饰文字或色块

### 供应商logo（290×254 近方形）
- 使用企业官方 LOGO 原文件
- 裁净白边后，完整显示居中（左右各 12px 留白）
- 白底，不添加任何装饰

### 操作步骤
1. 向用户索要官方 LOGO 原文件（或从 PDF/官网提取）
2. 自动裁净白边（trim transparent/white margins）
3. 按对应尺寸缩放，白底居中
4. 用户确认

## 素材获取

### 本地文件
- 优先从 `~/.hermes/shared/` 读取（绕过 macOS 沙盒）
- 用户通过 QQ 发送的文件在 `~/.hermes/cache/documents/`

### PDF 提取 LOGO
- pymupdf 提取 PDF 内嵌图片
- 优先检查前 3 页（LOGO 通常在封面/目录页）
- 注意 PDF 中的 LOGO 可能是反白版（白字），独立 LOGO 图需用彩色版（深色字）

## 交付与存档

- 所有成品存入 `~/Documents/欧卡_{产品名}_图片/`
- 同时备份到 `~/.hermes/shared/` 目录供后续读取
- 文件名必须包含 SKU 临时序号（从 SKU 归类表读取），不只用描述性名称

## 常见错误

| 错误 | 正确做法 |
|------|----------|
| 自己设计 LOGO（加色块、加文字、改配色） | 用官方原文件，只缩放裁剪 |
| 产品图做得像海报（渐变、场景叠加、装饰） | 干净产品照 + 版本标签，极简 |
| 截取位置不精确，船体不全 | 定位船体边界后再截，用户确认每一步 |
| 命名只有"汽油版""电动版" | 必须包含 SKU 临时序号 |
