# 船舶通用参数模板

## 概述
船舶建造（cat=164）下所有三级分类共用同一个参数模板，名称统一为「船舶通用」。共 79 个参数。

## 属性参数（4 个，标黄）
从 boatplus.cn 现有产品核实单位：

| 参数名 | 单位 | 说明 |
|--------|:----:|------|
| 总长 | m | 船加网筛选区间 0-10m |
| 航速 | kn | 船加网筛选区间 0-10kn |
| 最大乘员 | p | 船加网筛选区间 0-5p |
| 船体材料 | — | 文字型，无单位（如「玻璃钢」「高强度铝合金」） |

## 普通参数（75 个）
发动机重量、船底斜度、承船厢、等级、底角度、发动机品牌、艏侧推、航区、舱室数、动力、最大额定功率、压载体积、颜色、液压系统、肋距、废水、浮力容积、鼓风、标准、分散剂、总高、登陆航速、年份、梁拱、污水箱、溢油回收、月池、自持力、转向、轴发、充气压力、甲板服务吊、泥浆舱、抗风暴能力、居住舱、喷水器、泡沫、外部救生绳、制动拉力、滑轨斜面长度、发电机组、推荐马力、下甲板深度、材料、运营航速、最大航程、发电机功率、淡水、上建材料、干散货、压物舱、货物舱、耗油量、载重量、燃油容量、水线长度、垂线间长、甲板可用面积、船组人员、续航力、齿轮箱、机舱座位、艉侧推、污水、冷却系统、发动机功率、推进装置、最大航速、型宽、型深、吃水深度、推进方式、船型特点、海况级别、其他用途

## 模板结构
- Row 1: `标黄参数是"属性参数"`（黄色填充）
- Row 2: 分类名（如「船舶通用（无人船等）」）+ 79 个参数名（属性参数标黄）
- Row 3: 属性参数单位（标黄）

## 创建方式
用户可能以截图方式提供参数名。在 macOS 上用 Swift Vision OCR 批量识别：
```bash
swiftc ocr_screenshots.swift -o /tmp/ocr
/tmp/ocr /path/to/screenshots/*.png
```

参数单位：属性参数单位从 boatplus.cn 现有同类产品核实；普通参数单位从供应商产品资料录入，不要求统一。
