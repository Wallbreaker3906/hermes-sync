# 摘编规则详解

## 核心原则

推文是**引流工具**，不是信息公告。目标：让读者看完摘要后产生"必须扫码看全文"的冲动。

**禁止行为**：自己写一句话总结。必须从原文摘录，保留原文结构和措辞。

## 招标公告

### 必摘（保留）
- 项目名称、采购内容概括
- 项目编号/采购计划编号/项目代码（如有）
- 采购方式（公开招标/比质比价/竞争性谈判等）
- 资格要求概述（不必逐条列出，概括性描述即可）
- 开标方式（如"不见面开标"）
- 船舶/设备基本规格（吨位、尺寸区间、数量）

### 必删（隐藏）
- 所有联系电话、手机号 → `***`
- 所有邮箱地址 → `***`
- 具体投标截止日期和时间（只保留月份可）
- 精确预算金额
- 招标文件下载链接/URL → `(详见原文)`
- 联系人姓名
- 发布人/招标代理机构联系方式

### 保留示例
```
项目代码：2606-420607-04-03-172743
建设内容：新建20艘2000吨级集散两用新能源船舶
项目单位：襄阳通江运输有限公司（国有及国有控股）
建设性质：新建，拟开工时间2026-08
```

### 不保留示例
```
联系人：黄警官 0791-88892265  ← 删除
投标截止：2026年7月7日9:30    ← 删除
预算：33950816.80元           ← 删除
```

## 中标公告（更严格）

中标公告是最需要"留一手"的——读者最想知道的是"谁中标了、多少钱"，这些恰恰不能给。

### 必摘（保留）
- 项目名称、概况
- 项目编号/招标编号
- 招标方式（公开招标/直接采购/邀请招标）
- 开标时间（如原文有）
- 公示时间/公告期限
- 采购范围概述

### 必删（最关键）
- **中标方名称** ← 绝不出现
- **候选人名称及排名** ← 绝不出现
- **中标金额/投标报价** ← 绝不出现
- 联系人、联系电话、邮箱
- 评审专家名单
- 代理费金额

### 保留示例
```
项目编号：G1100000175277044001
采购方式：直接采购
项目类型：经营服务
公示时间：2026-06-16 至 2026-06-19
```

### 不保留示例
```
中标方：中国船舶集团第七〇四研究所    ← 删除
中标金额：2599万元                     ← 删除
候选人：江苏楚韵船舶修造，报价840万    ← 删除
```

## 每篇结尾

统一使用：
```
请扫描下方二维码登录查看
```

注意：
- 是「下方」不是「上方」
- 二维码紧随其后（不是隔很远）
- 每篇有独立的二维码，链接对应 boatplus.cn 原文
